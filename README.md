# Naruto Diamond

Версия **0.2**: сюжетная 2D CRPG по документу **Naruto Diamond Fandom RP 0.6**.
Кампания «Пепел под листвой» проходит через три главы: Тихая река,
руины Хасуми и закрытый архив. Созданный игроком шиноби ведёт отряд
к доказательствам о пропавших лекарствах и выбирает один из трёх финалов.

- Главное меню, настройки, кодекс, продолжение игры.
- Редактор имени, внешности, пути, клана, стихии, навыков, специализаций
  и 40 стартовых очков опыта; незаконный лист не допускается к игре.
- Иллюстрированные 2D-катсцены: пролог, переходы между главами и эпилог.
- Три карты, диалоги и улики, переговоры/засада/бой, разговоры с товарищами.
- Пошаговые сражения по d10, лечение, клоны, активации, огненный шар и барьер.
- Три ручных слота, автосохранение, экспорт/импорт JSON; старое локальное
  сохранение 0.1 сохраняется и переносится в автослот при первом запуске.

Это законченная небольшая кампания, а не весь справочник НРИ и не игра
масштаба BG3. Видео и озвучки нет: катсцены рисуются в Canvas. Полная
переносимость правил, ограничения и допущения описаны в
[docs/rules-scope.md](docs/rules-scope.md).

## Запуск

Нужен Node.js 22.12 или новее. Среда проверена на Node.js 24.19.

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```

Команды выполняются в распакованной папке проекта. Если PowerShell
блокирует `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd run dev`.
После запуска откройте адрес из терминала в браузере; терминал оставьте открытым.

Для обновления остановите старый сервер `Ctrl+C`, распакуйте свежий архив
в отдельную папку и выполните команды снова. Данные старой папки не удаляйте
до проверки новой версии. Сохранения браузера сохраняются при том же адресе
и порте сервера.

Vite запускает игровой клиент на порту 5173. Серверов БД, аккаунтов,
секретов или внешних игровых сервисов не требуется. Все изображения карты
рисуются Canvas; шрифты системные. Сохранение хранится в localStorage
конкретного браузера; при очистке данных браузера оно исчезает.

## Управление

- **Клик по карте** — пройти к клетке; отряд следует за выбранным шиноби.
- **Карточка персонажа** — выбрать его в исследовании. В бою выбран текущий
  союзник по инициативе.
- **F / кнопка «Действие»** — поговорить с дозорным рядом или забрать свиток.
- **M** — движение; **1** — выбрать кунай; **2** — огненный шар изучившего его героя;
  **3** — иллюзорный клон; **4** — изученная активация чакры;
  **5** — сосредоточение на уклонении; **6** — лечение; **7** — барьер.
- Для атаки сначала выбрать действие, затем кликнуть по противнику.
  Лечение требует союзника рядом; можно кликнуть по его карточке.
  Огненный шар задевает **и союзников** в области.
- **WASD / стрелки** — один шаг; **пробел** — завершить боевой ход;
  **Esc** — отменить выбранное действие или открыть меню. Цифры в диалоге выбирают ответ.
- На телефоне действия доступны через карту и кнопки.

В рамках одной главы обычная чакра не регенерирует сама. Между главами
проходит время на сюжетное лечение и подготовку; отряд восстанавливается. Шкалы здоровья, чакры и воли хранят
поверхностные и критические повреждения/расход отдельно. Подробные ресурсы,
атрибуты и навыки доступны по кнопке «Лист».

## Проверки и сборка

```bash
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

Node-тесты проверяют реальные расчёты d10, инициативу, действие/движение,
урон и броню, ресурсы, технику клонирования, лечение, огненный шар,
поведение противников, исходы миссии и проверку сохранений.
`dist/` — готовый статический сайт; он не хранится в Git.

## Устройство проекта

- `src/game.js` — логика пошаговой кампании без зависимости от браузера.
- `src/characters.js` — три законных стартовых листа и распределение опыта.
- `src/world.js` — карта, препятствия и места взаимодействия.
- `src/renderer.js` — отрисовка карты и персонажей.
- `src/main.js` — игровой интерфейс, диалоги и управление.
- `src/campaign-ui.js` — меню, редактор, сюжетные переходы и финалы.
- `src/creator.js` — проверка стартового листа и клановые формулы.
- `src/cinematics.js` / `src/campaign-data.js` — катсцены и сюжет.
- `src/saves.js` — ручные слоты и автосохранение.
- `tests/game.test.js` / `tests/campaign.test.js` — механики, редактор,
  карты, сохранения, прохождение и барьер.
